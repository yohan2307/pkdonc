# Pourquoi donc ? V2 — 1000 questions

Site statique prêt pour GitHub Pages.

- 1000 questions/réponses
- 100 thèmes documentaires
- réponses claires + humour
- recherche et filtres
- fiches détaillées
- question au hasard
- mode sombre
- responsive
- aucune base de données ni abonnement

Publier `index.html`, `style.css`, `script.js` et `questions.json` à la racine du dépôt GitHub, puis activer Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
